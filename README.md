🌤️ Live Weather Dashboard
A responsive Live Weather Dashboard built with HTML, CSS, and JavaScript using the Fetch API and Open-Meteo API.
✨ Features
🌡️ Real-time weather information
🔍 Search weather by city
☀️ Current temperature and weather condition
💧 Humidity
💨 Wind speed
🌡️ Real Feel temperature
🌧️ Chance of rain
🕐 6-hour forecast
📅 7-day forecast
🏙️ Save searched cities using LocalStorage
🗺️ City location map
⚙️ Celsius/Fahrenheit settings
🔄 Automatic weather refresh
📱 Fully responsive design
🛠️ Technologies Used
HTML5
CSS3
JavaScript
Fetch API
Open-Meteo API
LocalStorage
OpenStreetMap

🚀 How to Run
Download or clone this repository.
Open the project in VS Code.
Install the Live Server extension.
Right-click index.html.
Select Open with Live Server.
Search for any city and view its live weather.
📌 Project Purpose
This project was created to practice JavaScript Fetch API, API integration, DOM manipulation, LocalStorage, responsive design, and dynamic UI updates.
